# Security Specification — EliteDrive Self-Drive Car Rental Platform

## Collections & Access Boundaries
- **Public Read-Only Catalog & CMS (`cities`, `branches`, `vehicles`, `vehicleModels`, `vehicleCategories`, `insurance_packages`, `subscription_plans`, `company_settings`, `websiteSettings`, `businesses`, `socialLinks`, `coupons`, `offers`)**: Readable publicly; writable only by authorized Admin SDK routes or verified Admin/Owner accounts (`isAdmin()`).
- **Customer Private Data (`users/{uid}/private/info`, `kyc_verifications`, `customerDocuments`, `consent_records`, `bookings`, `payments`, `invoices`, `payment_proofs`, `refunds`, `inventory_holds`, `rental_agreements`)**: Customers can read only their own records (`userId == request.auth.uid`). Write access for sensitive operations is enforced through authenticated Express backend endpoints.
- **Server-Only Secrets & Sensitive Artifacts (`whatsapp_otp_challenges`, `payment_screenshots`, `kyc_document_blobs`, `company_assets`)**: Strictly `allow read, write: if false;` in `firestore.rules`. Payment screenshots are served exclusively via `GET /api/payment-screenshots/:proofId` and customer KYC documents via `GET /api/kyc/document/:docId` with RBAC ownership/permission checks and `Cache-Control: private, no-store`.
- **Firebase Storage (`storage.rules`)**: Private KYC uploads under `/customer-documents/{customerId}/driving-license/{fileName}` and `/customer-documents/{customerId}/aadhaar/{fileName}` plus `/payment-proofs/{customerId}/{bookingId}/{fileName}` enforce max 5MB limits and allow reads/writes only for the owning customer or authorized admins. Public company assets (`/company-assets/{allPaths=**}`) and vehicle media (`/vehicle-media/{vehicleId}/{fileName}`) are public-read / admin-write.
- **Operational Admin & Governance Collections (`owners`, `staff`, `roles`, `permissions`, `customers`, `inventory`, `maintenance`, `vehicle_private`, `vehicle_maintenance`, `booking_vehicle_assignments`, `audit_logs`, `auditLogs`, `payment_audit_logs`, `admin_notifications`, `staff_login_history`, `integrations_checks`, `systemSettings`, `aiSettings`, `migrationJobs`)**: Server-enforced RBAC with branch isolation (`assertBranchAccess` / `filterByBranch`) and Owner-only (`super_admin`) permanent data deletion & migration controls.
- **Verified Customer Reviews (`customer_reviews`)**: Only `Approved` reviews are publicly readable; review submission requires an authenticated customer owning a `Completed` booking.
- **Payments Policy**: Strictly Manual UPI (Company UPI ID / QR + Dynamic Deep Link + UTR + Payment Screenshot Finance verification) and Cash at Pickup where enabled. All online third-party payment gateways have been completely removed.

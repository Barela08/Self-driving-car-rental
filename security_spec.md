# Security Specification — EliteDrive Self-Drive Car Rental Platform

## Collections & Access Boundaries
- **Public Read-Only Catalog (`cities`, `branches`, `vehicles`, `insurance_packages`, `subscription_plans`, `company_settings`, `coupons`, `offers`)**: Readable publicly; writable only by authorized Admin SDK routes or verified Admin accounts.
- **Customer Private Data (`users/{uid}/private/info`, `kyc_verifications`, `bookings`, `payments`, `invoices`, `payment_proofs`, `refunds`, `inventory_holds`, `rental_agreements`)**: Customers can read only their own records (`userId == request.auth.uid`). Write access is blocked on Firestore client SDK and enforced through authenticated Express backend endpoints.
- **Server-Only Secrets & Sensitive Artifacts (`whatsapp_otp_challenges`, `payment_screenshots`)**: Strictly `allow read, write: if false;` in `firestore.rules`. Payment screenshots are served exclusively via `GET /api/payment-screenshots/:proofId` with signed HMAC-SHA256 tokens or RBAC-authenticated ownership/finance-permission checks and `Cache-Control: private, no-store`.
- **Operational Admin Collections (`vehicle_private`, `vehicle_maintenance`, `booking_vehicle_assignments`, `audit_logs`, `payment_audit_logs`, `admin_notifications`, `roles`, `staff_login_history`, `integrations_checks`)**: Server-enforced RBAC with branch isolation (`assertBranchAccess` / `filterByBranch`).
- **Verified Customer Reviews (`customer_reviews`)**: Only `Approved` reviews are publicly readable; review submission requires an authenticated customer owning a `Completed` booking.
- **Payments Policy**: Strictly Manual UPI (QR/Deep Link + UTR + Screenshot verification) and Cash at Pickup where enabled. Online third-party payment gateway routes (`/api/payments/razorpay/*`) are permanently disabled (`410 Gone`).
